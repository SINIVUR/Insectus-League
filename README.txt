던전 슬레이어 v0.0.7 — PWA 설치 패키지
=========================================

이 폴더를 HTTPS 웹 주소에 올리면 갤럭시 S23에서 앱처럼 설치할 수 있어요.
(파일을 폰에서 바로 열면 설치가 안 돼요. PWA는 https 주소에서만 설치돼요.)

[가장 쉬운 방법: Netlify Drop]
1. PC에서 https://app.netlify.com/drop 접속
2. 압축을 푼 'pwa' 폴더를 통째로 끌어다 놓기
3. 생성된 https 주소를 S23에서 열기

[GitHub Pages]
1. 저장소 맨 위(루트)에 이 폴더 안의 파일 7개를 그대로 올리기 (하위 폴더 없음)
2. Settings → Pages → Branch: main / root 로 저장
3. https://<아이디>.github.io/<저장소>/ 를 S23에서 열기

[S23에서 설치]
- 삼성 인터넷: 주소창 옆 ↓(다운로드) 아이콘 또는 메뉴 → '페이지 추가' → '홈 화면'
- Chrome: 메뉴(⋮) → '앱 설치' 또는 '홈 화면에 추가'
- 게임 메뉴 위쪽에 '앱 설치' 버튼이 보이면 그걸 눌러도 돼요.

설치하면 홈 화면 아이콘으로 전체화면 · 가로 고정으로 실행되고,
한 번 실행한 뒤에는 인터넷 없이도 플레이할 수 있어요.

['이미 설치되어 있다'고 나올 때]
- 홈 화면이나 앱 서랍에 '던전 슬레이어' 아이콘이 있으면 그걸 실행하면 돼요(다시 열 때 새 버전으로 바뀌어요).
- 아이콘이 없거나 다른 앱이 뜨면: 설정 → 애플리케이션 → 해당 앱 → 삭제 후 다시 설치하세요.
- 그래도 안 되면 브라우저 설정 → 사이트 설정(또는 사이트 및 다운로드) → 해당 주소 → 데이터 삭제 후 다시 설치하세요.
  (이 경우 그 주소에 저장된 게임 진행 데이터도 지워져요.)

[업데이트]
새 버전 파일로 같은 주소에 다시 올리면, 앱을 다시 열 때 새 버전으로 바뀌어요.
저장 데이터(레벨·장비·골드)는 기기 브라우저에 남아요.
